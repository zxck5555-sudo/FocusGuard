# FocusGuard (포커스가드) 🎯
> **스마트폰 특정 앱 사용 제한 및 집중력 향상 어플리케이션**

FocusGuard는 유튜브, 인스타그램, 틱톡, 웹툰, 게임 등 중독적인 앱 사용을 스스로 제어하기 어려운 사용자를 위해, 원하는 시간 동안 지정된 앱의 접속을 실시간으로 차단하고 집중력을 유지할 수 있도록 돕는 안드로이드 네이티브 앱입니다.

---

## 🌟 핵심 기능

1. **실시간 앱 실행 감지 및 즉각 차단 (0초 딜레이)**
   - **안드로이드 접근성 서비스(AccessibilityService)**를 탑재하여 차단 목록에 등록된 앱을 실행하는 순간 즉시 감지합니다.
   - 감지 즉시 앱을 최소화하고 홈 화면으로 이동시키며, 경고 진동과 함께 전체화면 차단 화면을 띄웁니다.

2. **유혹을 이겨내게 만드는 차단 오버레이 화면 (Blocker Screen)**
   - "지금은 집중할 시간입니다 🎯"
   - 실시간 남은 집중 시간 카운트다운
   - 충동적인 스마트폰 사용을 멈추게 하는 마인드셋 명언 카드
   - **엄격 모드 (Strict Mode)**: 충동적인 조기 해제를 방지하기 위해, 오타 없이 긴 반성 문장(*"지금 포기하면 후회할 것을 압니다."*)을 직접 타이핑해야만 세션 해제가 가능한 심리적 마찰(Friction) 장치 탑재

3. **직관적이고 세련된 집중 타이머 (Timer Screen)**
   - 대형 서큘러 프로그레스 애니메이션 타이머
   - 15분, 25분(뽀모도로), 45분, 60분, 90분, 120분 원터치 프리셋 및 슬라이더 조절 지원
   - 오늘 방어한 유혹 횟수(차단 시도 횟수) 통계 제공

4. **차단 대상 앱 손쉬운 관리 (App Selection)**
   - 기기에 설치된 모든 런처 앱 목록 로딩 및 실시간 검색 지원
   - **원클릭 프리셋**: 유튜브, 인스타그램, 틱톡, 넷플릭스, 페이스북, X(트위터), 크롬 등 대표적인 방해 앱 일괄 선택 기능

5. **꺼지지 않는 백그라운드 포그라운드 서비스 (Foreground Service)**
   - 사용자가 홈으로 나가거나 화면이 꺼져도 상단 상태바 알림을 통해 남은 집중 시간을 안정적으로 카운트다운합니다.
   - 기기 재부팅 시에도 세션이 남아있다면 자동으로 복구(`BootReceiver`)

6. **친절한 1-클릭 권한 설정 가이드 (Permissions Guide)**
   - 앱 차단에 필요한 4가지 권한(접근성 서비스, 다른 앱 위에 그리기, 알림, 배터리 절전 예외)의 활성화 여부를 실시간 표시하고 원클릭 바로가기 버튼 제공

## 📱 빌드된 APK 설치 방법

프로젝트 빌드가 완료되어 즉시 설치 가능한 디버그 APK 파일이 생성되어 있습니다:

- **생성된 APK 위치**:
  `app/build/outputs/apk/debug/app-debug.apk`

### 1. USB 디버깅(adb)으로 설치하는 경우
스마트폰을 PC에 연결하고 개발자 옵션의 USB 디버깅을 켠 뒤 터미널에서 다음 명령어를 실행합니다:
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

### 2. 스마트폰에 직접 복사하여 설치하는 경우
1. `app-debug.apk` 파일을 스마트폰으로 전송 (카카오톡 나에게 보내기, 구글 드라이브, USB 복사 등)
2. 스마트폰의 [내 파일] 앱에서 `app-debug.apk` 터치 후 설치 (출처를 알 수 없는 앱 설치 허용)
3. 앱 실행 후 **[권한/설정]** 탭에서 **접근성 서비스**와 **다른 앱 위에 그리기** 권한을 켜주시면 즉시 정상 작동합니다.

## 🛠️ 기술 스택 및 아키텍처

- **언어**: Kotlin 2.0.21
- **UI 프레임워크**: Jetpack Compose (Material 3)
- **비동기 처리**: Kotlin Coroutines & Flow
- **데이터 저장소**: AndroidX Preferences DataStore (초고속 캐싱 지원)
- **안드로이드 시스템 통합**:
  - `AccessibilityService` (실시간 앱 윈도우 상태 변경 감지)
  - `ForegroundService` with Notification (`specialUse` 타입)
  - `SYSTEM_ALERT_WINDOW` (오버레이)
  - `BroadcastReceiver` (`BOOT_COMPLETED` 복구)
